# Logos du visuel « duel de courtiers »

Contrôle du 30 septembre 2026. Les huit fichiers de `public/broker-logos/` viennent des éditeurs eux-mêmes. Ils servent uniquement à identifier les deux courtiers dans l’illustration, sans suggérer de partenariat.

| Fichier | Source officielle | Traitement |
| --- | --- | --- |
| `tr.svg` | [Contrat client France Trade Republic](https://assets.traderepublic.com/assets/files/CA_FR-en-fr.pdf), p. 1 | Recadrage vectoriel du logo, sans redessin des tracés. |
| `bourso.svg` | [Site BoursoBank](https://www.boursobank.com/) | SVG intégré à l’en-tête, entités HTML décodées. |
| `ibkr.svg` | [Logo Interactive Brokers](https://www.interactivebrokers.ie/images/common/logos/ibkr/interactive-brokers.svg) | Copie du fichier SVG publié par le courtier. |
| `fortuneo.svg` | [Site Fortuneo](https://www.fortuneo.fr/) | SVG intégré à l’en-tête ; couleur blanche explicitée pour rester visible sur fond sombre. |
| `xtb.svg` | [Logo XTB](https://xas-cdn.xtb.com/build/twigImages/svg-icons/logo/logo_xtb.svg) | Copie du fichier SVG publié par le courtier. |
| `caidf.svg` | [Logo Crédit Agricole Île-de-France](https://www.credit-agricole.fr/content/dam/assetsca/cr882/commun/images/logo/logo-2025.svg) | Copie du fichier SVG régional. |
| `bd.svg` | [Logo officiel Bourse Direct](https://groupe.boursedirect.fr/wp-content/uploads/2021/07/OFFICIEL_logo_Bourse_Direct.svg) | Copie du fichier SVG publié par le groupe. |
| `saxo.svg` | [Logo Saxo](https://www.home.saxo/-/media/global/logos/saxo-2022/saxo-beinvested-logo-blue.svg) | Copie du fichier SVG publié par Saxo. |

Le fond, les éclairs, les déchirures et le « VS » sont dessinés par l’application. Les logos sont affichés comme images intactes sur des panneaux séparés. La sortie PNG est produite dans le navigateur à partir du duo sélectionné.
