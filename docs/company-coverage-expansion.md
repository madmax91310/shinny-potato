# Extension automatique de couverture — octobre 2026

Cette extension qualifie les nombres moyens d’actions diluées et quatre exercices
consécutifs de Costco et Waste Management. Les valeurs sont relues dans les
communiqués consolidés officiels, avec rapprochement bénéfice/actions/BPA.

Costco publie les actions en milliers et les comptes en millions. Les colonnes
trimestrielles et annuelles sont distinguées, y compris les comparatifs de
52/53 semaines. Les anciens titres placés immédiatement avant les tableaux sont
rattachés uniquement lorsque le nom de l’émetteur, le titre consolidé et l’unité
sont explicites. Un cache de trois exercices ne bloque plus l’approfondissement.

Waste Management publie directement ses moyennes diluées. L’archive officielle
est lue sur quatorze communiqués pour couvrir quatre exercices annuels avec
leurs comparatifs. Son activation reste conditionnée à une collecte réelle sur
GitHub Actions : l’accès local seul n’est pas suffisant (ancien blocage HTTP 403).

Le contrôle intégral des divisions d’actions, les quatre FCF positifs consécutifs,
les sources de multiples historiques et les contrôles de fraîcheur sont conservés.
La migration de version des composantes force une nouvelle lecture des documents.
Le workflow quotidien existant renouvelle les données et déploie les observations
validées. Une erreur garde les anciennes dates et déclenche le signalement existant.

Le rapport de couverture quotidien ajoute le nombre d’exercices de cash et
d’actions disponibles, la qualification de leur base, la dernière période
estimée par la source et le nombre de multiples historiques. Ce diagnostic
n’est pas une mesure de précision prédictive.

Après collecte locale officielle : 27 entreprises actives, 11 modèles FCF et
23 modèles bénéfices (contre 26/9/22). Ce comptage dépend de la validation sur
runner et, ensuite, de la disponibilité et de la fraîcheur des données.
Les extraits de test incluent les URL exactes ; aucun chiffre de production
n’est saisi dans les adaptateurs. Les limites des autres entreprises restent
explicites : absence de composantes, de source qualifiée ou base par action
non comparable. Aucun seuil d’éligibilité n’a été abaissé.
