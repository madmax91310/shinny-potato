# Publications et données renouvelables

La publication présente l’activité, le cours daté, trois scénarios, les hypothèses du scénario sélectionné et un point de vigilance propre à l’entreprise. Les explications détaillées du calcul restent disponibles dans l’interface. Le texte distingue les estimations publiées des prolongements calculés par le modèle et les réglages personnels. Les rendements présentés concernent le cours, hors dividendes.

## Extension des collectes

- Disney : tableaux consolidés annuels de trésorerie, investissements, dividendes, rachats et rémunération en actions ; nombres moyens d’actions diluées publiés. Les dates complètes, unités et comparatifs sont contrôlés.
- Nike : nombres moyens d’actions publiés, conservés avec leurs sources. Aucun FCF n’est déduit du bénéfice ou d’un commentaire de direction.
- ServiceNow : lecture du libellé de nombre d’actions sur deux lignes, avec rapprochement bénéfice / nombre d’actions / BPA. Les divisions d’actions continuent de bloquer les modèles dont la base historique n’est pas qualifiée.
- Walmart et Netflix : une publication annuelle supplémentaire. Avec Booking, collecte des dividendes, rachats et rémunérations en actions identifiables dans les tableaux consolidés de flux. Le document Booking 2023 n’est pas retenu : son ancien format ne passe pas les contrôles du compte de résultat.
- Adobe : bilans annuels comparatifs et dernier bilan trimestriel, avec rapprochement du document avec les résultats et contrôle actif = passif + capitaux propres. Ces données alimentent les indicateurs de liquidité et de rentabilité des capitaux propres existants.

Chaque collecte redécouvre les publications sur les archives officielles. Une valeur absente reste absente ; une erreur de source ne renouvelle pas la date d’une ancienne observation. L’ajout de données ne modifie aucun seuil d’éligibilité des scénarios.

## Vérification

Les tests utilisent des extraits de documents publiés, notamment pour les unités, dates, colonnes, rapprochements et labels coupés. Sur GitHub, les nouvelles collectes sont relues directement depuis les sources, puis les données, scénarios et exports sont exercés dans Chromium. L’audit de couverture compte les périodes disponibles pour chaque champ ; il ne mesure pas l’exactitude des prévisions futures.
