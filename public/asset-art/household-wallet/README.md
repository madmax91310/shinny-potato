# Household wallet illustrations

Ten original AI-generated decorative scenes, created for the approved violet and copper sculptural direction. The subject changes with the statistic: securities, savings, wealth, property, credit, transmission, salary, budget, holidays and food. Mapping is explicit in `visualIdentity.js` for all 29 records.

Artwork contains no statistical quantities, series headings, logos or numerals. Exact figures, population, units, dates and source qualifications are drawn separately from the shared household data registry.

Each file is WebP (maximum 1200 × 800, quality 88) encoded as base64 text. The browser fetches only the selected scene and caches the decoded image; artwork stays outside the JavaScript bundles. Generated PNGs preserve the full artwork proportions and use canvas text at 2400 × 1620 pixels.
