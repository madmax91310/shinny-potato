# Performance depuis : néon

Illustrations originales générées avec ImageGen le 03/10/2026.
Atlas de production 5 × 4 : vingt scènes vert/or sur fond bleu nuit, extraites en WebP.
Le registre stylizedArt.js couvre explicitement les 43 actifs du calculateur.
Les entreprises utilisent une scène de leur activité ; lorsque le symbole vectoriel
vérifié existe déjà, sa silhouette exacte est éclairée par Canvas. Aucun logo inventé.
Bitcoin et Ethereum utilisent exclusivement leurs symboles vectoriels existants.
Les indices utilisent des scènes géographiques, jamais un logo d'émetteur ETF.
L'argent utilise un lingot gris ; l'or utilise un lingot doré.
Les scènes ne contiennent pas de données : chiffres et courbes sont dessinés par Canvas.
La courbe cumule les mêmes rendements annuels que le texte, fin N-1 à fin dernière
année complète. La comparaison se limite aux années communes ; aucune conversion.
