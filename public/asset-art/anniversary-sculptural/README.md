# Affiches sculpturales « Il y a X ans »

Direction approuvée par l’utilisateur le 30 octobre 2026 : maquette Bitcoin no 2,
puis Microsoft, ETF BNP Paribas Easy S&P 500 (ESE) et or. Fonds texturés bleu nuit,
socle sombre, illustration en relief, titrage et valeurs métalliques.

Les quatre fonds sans texte ont été dérivés avec ImageGen des images approuvées ;
`stage.webp` est leur scène vide commune pour les autres logos vérifiés. Les marques
sont représentées dans les deux scènes de référence Bitcoin/Microsoft ; elles ne
sont pas ajoutées une deuxième fois. Pour les autres entreprises, le fichier officiel
local est affiché sans recadrage, étirement, filtre ou recoloration, sur une plaque
claire de contraste. Aucun logo d’émetteur n’est substitué à celui d’un indice/ETF.
Le décor américain est une illustration d’exposition, pas un logo de fonds.

Tous les textes et chiffres sont rendus par Canvas à partir des observations
qualifiées existantes. Aucun prix, taux ou nombre d’années n’est dans les fonds.
Le libellé de droite est « AUJOURD’HUI » pour tous les actifs, conformément à la
consigne éditoriale ; les dates d’observation et le contrôle de fraîcheur restent
inchangés dans le registre, la saisie et le tweet.

Les fontes locales Nimbus Roman proviennent de URW Base 35 ; leur licence complète
figure dans FONT-LICENSE.txt. Aucun chargement distant pendant l’export.
