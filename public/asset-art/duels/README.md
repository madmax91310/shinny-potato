# Duel de portefeuilles — cartes en titane

Direction 3 validée le 4 octobre 2026 : deux plaques gravées symétriques, relief et reflets titane, accents émeraude/or. Les surfaces, filets et typographies sont dessinés par canvas ; les nombres restent dérivés du duel réel. Une illustration par ligne, dans le même ordre que les actifs/poids. Un petit poids conserve une illustration lisible : la taille de l’objet n’est pas un graphique d’allocation.

Les scènes proviennent exclusivement de la collection vérifiée `etf-night` (voir son README pour les sujets, prompts et contrôle visuel). Aucun nouvel emblème ni logo d’émetteur n’est inventé. Les illustrations de globe désignent une famille d’exposition ; le libellé exact distingue ACWI, All-World, World hors USA, facteurs, émergents, petites capitalisations ou dividendes. Les noms et poids ne sont jamais intégrés dans les images sources.

`src/pages/portfolio-duels/visualIdentity.js` référence explicitement chaque exposition du catalogue : actions mondiales/facteurs/dividendes → globe monde, américaines → Amériques, européennes → Europe, Japon/Inde → Asie ; obligations et monétaire → certificats ; technologies/puces/IA/blockchain → processeur ; santé/biotech → hélice ; financières → architecture bancaire ; énergie → pétrole ; cybersécurité → bouclier ; robotique → bras industriel ; eau → goutte ; luxe → montre ; batteries → cellules ; énergies propres → renouvelables ; infrastructures → pont/réseau ; immobilier → immeubles.

Les calculs, le change déjà utilisé par le duel, les années communes et le texte du tweet sont inchangés. L’image affiche les dates, la mise de départ, tous les actifs/poids, le capital final et la performance cumulée des deux côtés, l’écart final et les rendements annuels. Aucun titre de série/portefeuille. L’export attend les scènes et la police locale, rejette une identité inconnue et permet de réessayer un chargement échoué.

`node scripts/test-duel-titanium.mjs` vérifie dans Chromium les 45 supports, les 28 duels préparés, trois lignes de chaque côté et les historiques courts, les scènes réellement dessinées (ordre et nombre), les libellés complets, poids, capitaux, résultats annuels/cumulés, égalités, pertes, grands nombres, absence de chevauchement, une signature et le téléchargement/reprise/mobile. Les PNG représentatifs se trouvent dans l’artefact CI `duel-visual-checks`.
