# Présentations : logo en relief

Direction 1 validée le 9 octobre 2026. Deux décors créés par génération d’images : scène immobilière pour les SCPI, studio de verre pour les assurances vie. Les décors ne contiennent aucun chiffre ni logo. Export WebP qualité 92.

Le rendu Canvas utilise les logos officiels locaux (provenance dans `../presentation-logos/sources.json`), leur contour extrudé, une palette par placement et trois indicateurs tirés des observations partagées. Les SVG ont une taille intrinsèque de 1600 pixels pour éviter la pixellisation à l’export. Les badges Linxea sont détourés par luminosité pour conserver les lettres et le symbole blancs.

SCPI : dernier taux de distribution publié, prix de part et minimum initial. Assurance vie : derniers rendements des fonds euros (fourchettes et conditions incluses) et gestion des UC ; ouverture lorsqu’un seul fonds est présent. Les conditions détaillées restent disponibles dans la publication et les sources de l’outil.
