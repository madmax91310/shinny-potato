# Same Bitwise share, independent Paris quotation

Captured 10 November 2026 by the ordinary issuer download and the existing
`collect_one` monthly adapter. This is a real local source check, not a GitHub
scheduled run. `issuer.html.gz` is the public exact-share page
https://bitwiseinvestments.eu/products/bitwise-physical-bitcoin-etp/.
Each trading row binds ISIN, venue, currency, RIC and listing date. The Paris
listing starts 1 June 2021; the fund's 2020 inception cannot extend it backwards.

`collected.json.gz` contains both actual Yahoo responses, 65 independently
bucketed daily/monthly endpoints, the corporate-action probe, exact timezone,
method, URLs and response hash. Financial type is ETN; Yahoo's own classification
ETF is checked separately. EUR exchange prices are not USD NAV. No distribution
or split is inferred from a product name and no adjustment is applied again.

This independent route does not explain or overwrite the old Xetra observations,
financial divergences or their restrictions. The original ticker remains in the
catalogue with its actual failure and preserved last valid data. Ordinary GitHub
collection, publication and browser consumption must be demonstrated separately.
