# Fixture de régression

Extrait numérique limité de la fiche courante Invesco Bloomberg Commodity UCITS ETF IE00BD6FTQ80, composition d’indice au 31 août 2026, téléchargée le 7 octobre 2026.

Source : https://www.invesco.com/content/dam/invesco/emea/en/product-documents/etf/share-class/factsheet/IE00BD6FTQ80_factsheet_en.pdf

L’extrait conserve uniquement identité, ticker d’indice, intitulés de sections, sept groupes et date du tableau. Les tests vérifient l’identité exacte, les dates, les doublons, les tableaux tronqués, la conservation de l’arrondi signé et la protection contre la régression de date. Les valeurs ne sont pas un repli de production : chaque collecte télécharge le document courant.
